## AI Usage Disclosure

The CSS and parts of the HTML were written by my local AI agent
(`rise-ai-agent`). Nothing else was coded using AI. All the logic is 100% made by hand by me.
No JS file was ever touched by an AI.

I didn't want to spend countless hours perfecting the initial design. Given
where my actual goals are, lower-level systems programming and AI, polishing
CSS would have been time poorly spent, so at the end I let my agent handle the
design.

I could also have spent hours refactoring the non-optimal parts of the finished
app. To be honest, I was already tired of the project: it had exceeded the
course requirements by a pretty large margin, and further refactoring would
have been exhausting with diminishing returns.
